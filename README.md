# CavoSkill

CavoSkill is a web-based platform for selling and managing online courses. The project was developed as a simulation of a complete e-learning platform, with a focus on user management, course purchasing and database integration.

## Features

- User registration and login
- User profile management
- Browsing available courses
- Course purchasing
- Purchased courses overview
- Certificate management
- Database integration
- Course and user data management
- Downloadable certificates

## Technologies

- PHP
- MySQL
- HTML
- CSS
- SQL
- JavaScript

## Database

The project uses MySQL for storing and managing users, courses, purchases and other platform-related data.

The `cavoskill.sql` file contains the database structure and data required for the project.

## Purpose

The project was created as a practical demonstration of web development using PHP and MySQL, combining frontend design with backend logic and database management.
